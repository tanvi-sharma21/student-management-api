# Student Management API

A beginner-friendly backend project built with Python and FastAPI.

## Features

- Get all students
- Get student by ID
- Add a student
- Update a student
- Delete a student
- Search students
- Filter students
- Student statistics
- Find low-attendance students
- Find top students

## Technologies

- Python
- FastAPI
- Pydantic
- Uvicorn

## Storage

Currently uses an in-memory Python dictionary.
Database integration will be added in a future project.

## How to Run

```bash
uvicorn main:app --reload
